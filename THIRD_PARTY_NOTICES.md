# Third-party software

The desktop bundle contains dynamically linked third-party libraries and a Python runtime.
Their license files are included in `Contents/Resources/licenses` where supplied by the distributions.

- CPython: Python Software Foundation License — https://www.python.org/
- Qt / PySide6 / Shiboken: LGPLv3 and other licenses listed with Qt — https://www.qt.io/licensing/open-source-lgpl-obligations and https://code.qt.io/
- Qt WebEngine / Chromium: component-specific open source licenses — https://doc.qt.io/qt-6/qtwebengine-licensing.html
- pygame / SDL: LGPL and zlib respectively — https://www.pygame.org/ and https://www.libsdl.org/
- hidapi: BSD/GPLv3/original HIDAPI license alternatives — https://github.com/libusb/hidapi
- websockets: BSD — https://github.com/python-websockets/websockets
- PyInstaller bootloader: GPL with the distribution exception — https://pyinstaller.org/en/stable/license.html

The application source, build recipe and modifications are available at:
https://github.com/peterpyyyyy/spacemouse-swerve

Their game code and assets are not included in this bundle. This app is not affiliated with 3Dconnexion, FIRST, Qt, or those simulators.
